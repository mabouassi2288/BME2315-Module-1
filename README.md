# BME2315-Module-1
Alzheimer's Disease
The main data files you should be looking at are main_Mona_and_Cece.py and patient_Mona.py. These two files have all the coding required for this project. DO NOT VIEW mina_Cece.py, THIS IS UNCOMPLETED CODE FROM BEFORE THE PROJECT WAS FINISHED!
The code includes printing all the headers from the data set, sorting the patients by increasing pTAU value, filtering the data set to only show patients who died in their 80s with ABeta42 levels less than 50, and four graphs produced with statistical analyses for all of them (including ANOVA, p-value test, and outlier test, depending on the graph).
